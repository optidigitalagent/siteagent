# Concept prototyping

Create real, responsive static HTML/CSS/JS prototypes, not mock JSON or color directions. Each
concept must express a distinct central idea through composition, hero, rhythm, media, typography,
CTA and signature element. Render desktop/mobile before selection and preserve the rationale next
to the prototype. Category is context, never a layout selector.
