# Accessibility review

Require semantic landmarks and headings, correct page language, meaningful media alternatives,
visible keyboard focus, labelled controls, sufficient contrast, responsive zoom and reduced-motion
fallback. Require semantic header/nav/footer landmarks, reachable persistent navigation and a
footer conversion route. Primary CTA text must remain visible, focusable and inside its clickable
box in every state. Do not remove focus, rely on color alone or make images the sole action.
