# Anti-template review

Compare concept idea, composition, hero, density, DOM, typography treatment, CTA closure,
signature element and repeated phrases. Primitive/token reuse is allowed; a full-layout match is
not. Require a new concept or material redesign, never an accent-color swap, when similarity is high.
