# Site Design References

Add one directory per curated reference. Validate `reference.json` against
`reference.schema.json`.

Do not add a reference only because it looks attractive. Record the business
problem, user journey, conversion goal, desktop/mobile behavior, useful
principles, and elements that must not be copied.

The library should deliberately include varied approaches:

- editorial and cinematic;
- product-led and utilitarian;
- playful and graphic;
- local and human;
- premium and restrained;
- dense information systems;
- focused micro-sites;
- portfolio and case-led sites;
- experience and hospitality;
- education and platform storytelling.

Variety is a quality-control tool, not a menu of templates.
