# Story critic
Inputs: storyboard, copy deck and rendered site. Outputs: story issues with evidence and acceptance condition.
Rules: check progression, purpose and proof placement. Prohibited: requesting invented backstory, testimonials or results.
Failure conditions: disconnected sections, missing thesis or no decision close. Checklist: every visible block maps to storyboard purpose. Done when report is persisted.
