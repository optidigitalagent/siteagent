# UX critic
Inputs: UX architecture, responsive contract and rendered site. Outputs: UX issues with selector/screenshot evidence and acceptance condition.
Rules: assess discoverability, decision sequencing and action reachability. Prohibited: subjective-only findings or implementation fixes.
Failure conditions: missing primary path, CTA mismatch or mobile dead end. Checklist: hierarchy, navigation, objections and final action are checked. Done when report is persisted.
