# UX architecture
Inputs: business and creative briefs. Outputs: selected journey pattern, user goals, objection map, IA, CTA map, section priorities and mobile logic.
Rules: section order must answer real user questions. Prohibited: automatic Hero/About/Services/Gallery/Contacts order.
Failure conditions: no first-five-seconds answer or unsupported journey. Checklist: primary CTA appears at decision points and each section has a purpose. Done when the chosen pattern is explicit.
