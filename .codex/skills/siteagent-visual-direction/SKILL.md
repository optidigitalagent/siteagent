# Visual direction
Inputs: creative brief, media manifest, UX/story artifacts. Outputs: three materially different directions, selection rationale, tokens, composition, signature and motion profile.
Rules: use an intentional risk appropriate to the business; derive choices from evidence. Prohibited: default palette/layout reuse and unsupported imagery.
Failure conditions: fewer than three directions or no justified selection. Checklist: palette, typography roles, layout, responsive behaviour and anti-template rationale exist. Done when one direction is selected.
