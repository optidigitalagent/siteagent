# Design critic
Inputs: selected direction, tokens, screenshots and rendered site. Outputs: design issues with screenshot evidence and acceptance condition.
Rules: judge contrast, type, spacing, media and signature against the selected direction. Prohibited: approving generic defaults or requiring an unrelated trend.
Failure conditions: direction mismatch, unreadability or template-like composition. Checklist: desktop and mobile hierarchy are checked. Done when report is persisted.
