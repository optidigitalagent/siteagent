# Media director
Inputs: scrape assets and research sources. Outputs: media manifest with checksum, dimensions, quality, crop, alt text, selected/rejected status.
Rules: distinguish Instagram UI from media; describe only visible verified content. Prohibited: stretched low-resolution assets or inferred subjects/events.
Failure conditions: unavailable hero is presented as proof, or asset metadata is missing. Checklist: source, use case, focal point, mobile crop and rejection reason are recorded. Done when all candidates are classified.
