# Conversion copy
Inputs: evidence, strategy, UX architecture and storyboard. Outputs: copy deck, microcopy, section copy, proof requirements and CTA wording.
Rules: use specific active language and preserve approved CTA. Prohibited: generic AI phrases, fake metrics/reviews/prices, placeholder text and raw internal uncertainty.
Failure conditions: unsupported claim, weak hero, or CTA mismatch. Checklist: first screen answers business/offer/action and all claims trace to evidence. Done when the copy deck validates.
