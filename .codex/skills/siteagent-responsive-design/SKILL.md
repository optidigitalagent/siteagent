# Responsive design
Inputs: selected visual direction, UX architecture and copy deck. Outputs: responsive contract, breakpoints, hierarchy, crop and interaction rules.
Rules: retain the decision path on small screens; targets are at least 44px where interactive. Prohibited: desktop-only assumptions, horizontal overflow and hover-only actions.
Failure conditions: absent target viewport or unreachable CTA. Checklist: 1440, tablet and 390 behaviour are specified. Done when the contract validates and browser checks pass.
