# Design Reference Library

The reference library teaches taste and range. It must not become another
template catalog.

## Location

Store curated references under:

`references/site_designs/<reference-id>/`

Recommended files:

- `reference.json`
- `desktop.png`
- `mobile.png`
- optional `notes.md`

## What each reference records

- source and title;
- business/product context;
- audience and conversion goal;
- atmosphere and design traits;
- composition and narrative;
- typography and spacing;
- media treatment;
- interaction and motion;
- mobile behavior;
- what is worth learning;
- what must not be copied;
- when the reference is relevant;
- when it is misleading.

Use `references/site_designs/reference.schema.json`.

## Selection rule

Select references by a combination of traits, not by category alone:

- business model;
- audience;
- price/positioning;
- media quality;
- atmosphere;
- conversion goal;
- information density;
- brand personality.

A yacht business may learn composition from a fashion editorial, conversion
from hospitality, and media rhythm from architecture. It must not receive a
`yacht template`.

## Synthesis rule

For each concept, cite the principles taken from references and explain how they
were transformed for the current evidence. Never reproduce the same layout,
copy, signature element, or complete visual system.

## Human workflow

When the user supplies a screenshot or link:

1. Save or reference it.
2. Describe precisely what the user likes.
3. Record what would be wrong to copy.
4. Tag its reusable traits.
5. Add it to the library index.
6. Let Creative Studio use it as one influence among several.

References never override factual evidence or accessibility.
