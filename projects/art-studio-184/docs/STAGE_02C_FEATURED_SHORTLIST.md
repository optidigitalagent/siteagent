# Art Studio 184 — featured shortlist Stage 2C

Дата: 2026-08-02
Статус: 12 provisional projects для первой версии; internal labels не являются публичными project names.

## Selection rules

- Ровно 4 проекта в каждой из трёх категорий.
- Один объект с несколькими кадрами считается одним project.
- Exact duplicates исключены.
- Предпочтение отдано законченному результату, разнообразию масштаба/тона, понятному силуэту и пригодному crop.
- Workshop clutter, низкое разрешение, Instagram UI, повторяемость и third-party marks учитывались как deductions.
- Все проекты требуют owner confirmation границ группы; client/material/date/location/result не выводятся из изображения.
