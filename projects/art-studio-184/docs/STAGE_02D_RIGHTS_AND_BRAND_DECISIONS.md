## Формальное подтверждение по selected assets

Stage 2B уже фиксирует слова владельца: фотографии связаны с Art Studio 184 и разрешены для нового сайта. Сейчас требуется не повторный factual опрос, а письменная фиксация границ прав для конкретно выбранных кадров.

   Исключения: _______________________________________________________

2. Подтверждаю, что выбранные фотографии можно использовать на новом коммерческом сайте Art Studio 184.
   Ответ владельца: ДА / НЕТ / НУЖНО УТОЧНИТЬ
   Исключения: _______________________________________________________

3. Подтверждаю, что фотографии сделаны студией либо переданы студии с разрешением на такое использование.
   Ответ владельца: ДА / НЕТ / НЕ ЗНАЮ
   Где хранится evidence: ____________________________________________

4. Подтверждаю, что публикация выбранных кадров не нарушает известные договорённости с заказчиком.
   Ответ владельца: ДА / НЕТ / НУЖНА ПРОВЕРКА
   Исключения: _______________________________________________________

5. Подтверждаю, что видимые сторонние бренды можно показывать в пределах решений по каждому проекту выше.

## Что не разрешает даже положительный owner answer

- называть видимый бренд клиентом или партнёром без отдельного evidence;
- использовать client-logo strip;
- утверждать authorship, material, dimensions, location, date или result без metadata;
- скрывать disputed mark так, чтобы изображение вводило в заблуждение;
- считать owner answer юридическим заключением или разрешением правообладателя;
- публиковать кадр со статусом `UNRESOLVED`.
