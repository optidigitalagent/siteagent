Дата подготовки: 2026-08-02

## Необходимые фотографии

- общий вид мастерской без конфиденциальных данных;
- CNC в работе и общий вид оборудования;
- 3D-принтер/печать в работе;
- ручное формообразование/скульптура;
- обработка пенополистирола;
- работа со стеклопластиком, если безопасно и допустимо показывать;
- металлокаркас/сварка;
- работа с деревом;
- последовательность `шпаклевание → шлифование → грунтование → покраска → покрытие`;
- сборка;
- подготовка к доставке;
- монтаж на площадке;
- детали поверхности и человек рядом с объектом для масштаба.

Для каждого кадра нужны автор, владелец прав, разрешение, дата/source, связь с Art Studio 184 и честный claim role.

## Утверждения, которые пока запрещены

- `усі етапи виконуємо самі`;
- `майстерня повного циклу`;
- конкретные модели, рабочие размеры, tolerances и capacity;
- перечень поддерживаемых материалов;
- indoor/outdoor пригодность без условий;
- weather resistance, гарантированный срок службы и долговечность в годах;
- доставка или монтаж в конкретной географии;
- фиксированные сроки производства;
- любое in-house утверждение без owner confirmation и evidence.

Статус каждого такого утверждения: `BLOCKED FOR PUBLICATION`.

## Различие сущностей

- **Услуга** — то, что мастерская предлагает заказчику как самостоятельный результат или обязательство.
- **Материал** — физическая основа/состав объекта; сам по себе не доказывает услугу.
- **Технология** — способ изготовления; не обязана становиться отдельной публичной услугой.
- **Этап производства** — часть пути проекта; не должен дублировать готовый тип результата из Gallery.

До заполнения матрицы ни одна из шести групп не становится публичным production claim.
