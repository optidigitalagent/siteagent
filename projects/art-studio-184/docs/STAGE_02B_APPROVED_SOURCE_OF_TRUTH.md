# Art Studio 184 — утверждённый source of truth этапа 2B

Дата: 2026-08-02
Статус: утверждённый factual и operational contract для последующих этапов. Сайт, дизайн-система, финальный копирайтинг и код этим документом не создаются.

## 1. Иерархия источников

1. `STAGE_02B_OWNER_RESPONSES_AND_CODEX_TASK.md` — актуальные ответы владельца; они отменяют противоречащие им рабочие гипотезы этапов 0–2A.
2. Документы Stage 01 — утверждённые structural contracts: пять routes, blueprints, user journey, CTA architecture и SEO backlog, если они не переопределены владельцем.
3. Непротиворечащие реестры Stage 02A — предыдущие статусы, вопросы и ограничения; ответы владельца Stage 02B закрывают или изменяют их явно, не переписывая историю.
4. Stage 00 — audit facts о репозитории, черновике, reference site и portfolio source.
5. Публичные источники из входного документа — только evidence, а не разрешение усиливать claims: черновик, Unique Rabbit, портфолио и Google Maps.
6. Два tracked reference assets — только для будущей секции команды в указанных ниже ролях.

При конфликте сохраняется исторический документ, а актуальным считается решение владельца из этапа 2B. Неизвестное значение не выводится из фотографии, черновика или референса.

## 2. Система статусов

| Статус | Значение |
| --- | --- |
| `CONFIRMED` | Владелец подтвердил значение; оно может войти в последующие рабочие контракты с указанными ограничениями. |
| `CONFIRMED / EVIDENCE PENDING` | Владелец подтвердил факт, но файл, документ, фото, реестр или формальное разрешение ещё не приложены. |
| `PROVISIONAL` | Рабочее решение принято, но требует отдельной фиксации или может измениться. |
| `NEEDS EVIDENCE` | Нужен источник, файл, техническая характеристика, фото или разрешение. |
| `BLOCKED FOR PUBLICATION` | Публичный вывод или функция запрещены до закрытия условия. |
| `DEFERRED` | Данные сознательно перенесены на более поздний этап. |
| `DO NOT PUBLISH` | Утверждение запрещено публиковать. |

Составные qualifiers из owner document сохраняются дословно и сужают базовый статус: `CONFIRMED / IMPLEMENTATION PENDING`, `CONFIRMED / LEGAL TEXT PENDING`, `CONFIRMED BY OWNER / FORMAL EVIDENCE PENDING`, `PROVISIONAL / NEEDS EVIDENCE` и `DEFERRED / NEEDS OWNER INPUT`.

## 12. Запрещённые утверждения

Статус всех строк ниже — `DO NOT PUBLISH`, если прямо не указано условие снятия запрета:

- `найдешевші`, `найкращі`, `преміальні` и другие абсолютные superiority claims без evidence;
- `зробимо за один день`, другой фиксированный общий срок или обещание срока ответа;
- фиксированная гарантия, срок службы, погодостойкость или бесплатное исправление без отдельного contract;
- международный монтаж;
- конкретные зарубежные страны/условия международной работы без подтверждения;
- модели, размеры, материалы, допуски, производительность, capacity и другие технические цифры оборудования;
- конкретные бренды материалов/поставщиков и сравнительные свойства без списка/evidence;
- выдуманное юридическое лицо, ФОП, реквизиты или privacy facts;
- client relationship, логотип клиента, review или award без источника и разрешения;
- project title, material, size, date, location, result или client по визуальному предположению;
- вымышленные портреты команды или фотографии людей из layout reference;
- названия конкурентов и обвинительная версия сравнительной истории;
- ложный form success, если Telegram-бот не подтвердил приём;
- утверждение, что доставка всегда выполняется собственными силами;
- точный label `майстерня повного циклу` без отдельного утверждения; разрешён только подтверждённый смысл пути от разработки и производства до организации доставки и монтажа;
