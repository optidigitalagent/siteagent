# Art Studio 184 — реестр проектов и медиа

Дата подготовки: 2026-08-02
Назначение: зафиксировать правила проектной сущности, предварительный shortlist и незакрытые права без скачивания или переноса 190 публичных файлов.

## A. Правила сущности Project

1. Один реальный объект или один заказ — один `Project`.
2. Несколько ракурсов, этапов или контекстов одного объекта связываются с одним `project_id`.
3. Exact duplicates не создают новых проектов и не увеличивают perceived case count.
4. Совпадение имени `name.jpg` / `name (2).jpg` не доказывает ни дубликат, ни общий проект; нужна визуальная и owner-assisted группировка.
5. Один проект получает одну primary category; дополнительные связи не создают копию проекта.
6. Название, клиент, материал, размер, дата, локация, задача и результат не выводятся без источника.
7. Проект не публикуется без asset-level прав на каждый rendered frame.
8. Публичная фотография не считается автоматически разрешённой для нового коммерческого сайта.
9. Сторонний бренд в кадре не доказывает клиентские отношения и требует отдельной проверки.
10. Shortlist ниже — только кандидаты для ответа владельца; он не является финальной art-direction selection.

Stage 00 установил: 190 unique displayed assets в трёх series, 150 portrait, 38 landscape, 2 square; 2 exact duplicate pairs и 46 filename-collision pairs. Эти числа описывают файлы, а не количество проектов.

## E. Технические требования

Для каждого утверждённого asset обязательны:

- high-resolution original, а не screenshot/social UI;
- managed production storage;
- checksum и неизменяемая source record;
- WebP/AVIF derivatives при сохранении original;
- responsive variants и `srcset/sizes` plan;
- width/height metadata;
- crop/focal-point notes для desktop и mobile;
- alt source facts, не придуманные по изображению;
- project_id, frame order, author, rights holder и permission;
- canonical provenance type и allowed-use boundary.

GitHub Pages portfolio не используется как production CDN. До подтверждения прав выбранные файлы не переносятся в проект и не рендерятся в публичном сайте.
